# 第一章 数据库基础

## 1.1 关系模型

### 关系模型的基本概念

关系模型使用关系表示现实世界中的对象及其联系。关系可以看作由行和列组成的二维表，行表示元组，列表示属性。每个属性应具有明确的取值范围。

### 关系模式

关系模式描述关系的结构，通常写作 R(A1, A2, …, An)。其中 R 是关系名，A1 到 An 是属性名。关系模式规定了表的列、属性含义和约束。

## 1.2 关系模型与关系模式的联系

关系模型是数据库的总体数据模型，关系模式是关系模型在具体数据库中的结构描述。关系模式依赖关系模型提供的表结构表示方式，并进一步规定具体属性和约束。

# 第二章 数据库设计

## 2.1 函数依赖

在关系模式中，如果属性集 X 的值能够唯一确定属性集 Y 的值，则称 Y 函数依赖于 X，记作 X → Y。函数依赖用于表达属性之间的确定关系，是分析关系模式结构的重要工具。

## 2.2 规范化

规范化通过分解关系模式减少数据冗余和更新异常。第一范式要求属性值保持原子性；更高范式还需要结合候选键、完全函数依赖和传递依赖进行判断。

## 2.3 函数依赖与规范化的联系

函数依赖是规范化分析的基础。设计者先根据业务语义识别函数依赖，再利用候选键和依赖关系判断关系模式是否满足相应范式。
