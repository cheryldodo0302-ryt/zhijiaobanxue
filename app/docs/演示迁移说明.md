# 演示系统迁移

当前采用本地存储方案，账号、班级、课程、教学档案、已发布知识及上传文件随文件夹一起迁移。

1. 停止正在进行的上传和解析，关闭智教伴学启动窗口。不要在服务写入时复制数据库。
2. 自行压缩当前整个项目目录，不需要运行导出脚本。压缩包必须同时包含根目录的 `智教伴学.exe`、`installers` 和 `app`。
3. 在新 Windows 电脑完整解压到有写入权限的目录，然后双击 `智教伴学.exe`。不需要输入 PowerShell 指令。
4. 等待自动准备环境、启动服务并打开浏览器。继续使用原账号和密码登录。

必须保留：

- `app/data/` 整个目录，包括 `learning.db`、`study_room.db`、`uploads/`、`auth_secret` 及隐藏的 `.job-secret.key`。不要只复制数据库。
- `app/web/dist/` 已构建界面，包括 `assets`、`models` 和 `mediapipe` 子目录。
- `app/server.env`、`app/user_ai.env`（如有）、`app/relay_client.env`（如有）及全部程序源码。
- `installers/` 中的 Python 安装器与校验文件。

可选排除：`.venv*`、`app/web/node_modules`、`app/.runtime`、缓存、旧 `exports` 和 `tmp`。复制这些目录也可以，启动器会检查并修复失效虚拟环境。不要删除 `app/web/dist`。

新电脑无需预装 Node.js；没有 Python 3.10–3.12 时，启动器会使用随附安装器自动安装项目专用 Python。首次安装 Python 依赖需要联网。已配置的远程 AI、MinerU、Pix2Text 等服务仍需可访问。当前实现验证了本机启动和目录迁移；全新 Windows 电脑的安装器流程仍需在目标机器实际运行确认。

首次启动按当前数据目录修复数据库里的原文件、预览图、教学档案、解析产物及结构化 JSON 路径，也修复解析 manifest 中的路径字段；保留账号密码和学习记录。以后再次更换盘符或目录也会重新修复。逻辑来源目录、章节标题及正文不会被替换。

## 展示账号与教学档案

新增教师账号 `showcase_teacher`（林**，演示），密码见 `app/data/showcase/展示账号说明.txt`。原有 `demo_teacher` 及其课程和上传资料保留。

展示课程为数据库原理与应用、Python程序设计、医学人工智能导论。每门课关联 信管1班、2班，共6个教学班；每班30人，跨课程共用同一批60名学生，全部为虚构数据。

每门课程包含教学大纲、16次教案、16周进度、8个实验项目、8条模拟教学反思、考核方案与3个考核分项，并提供可预览/下载的 UTF-8 来源文件。学时为64（理论32、实验32），考核权重为20%+30%+50%。课程学习手册已审核发布，班级学生可查看原文件。

学生账号范围为 `2026240101`–`2026240130` 和 `2026240201`–`2026240230`，初始密码与账号相同。仅这些专用展示账号免首次改密；自行修改后使用新密码。完整名单见 `app/data/showcase/学生账号名单.csv`。普通教学班新导入学生仍首次登录改密。

创建展示数据前的数据库备份位于 `app/data/backups/before-portable-showcase-*.db`。重复执行展示数据脚本不会重置账号密码、清除原课程或重复创建资料。

`导出演示包.cmd` 仍是可选的自动导出方式；手动压缩整个目录即可。迁移后原浏览器登录状态不会随目录复制，需使用原账号重新登录。项目包含私人配置及账号数据，请仅保存为自己的迁移副本。


## 学习展示数据（补充）

所有姓名仅显示姓氏与掩码，校区和年级使用演示值。`data/showcase/展示脱敏名单.csv` 可用于投屏，账号和密码均已遮盖；实际登录使用 `展示账号说明.txt` 和 `学生账号名单.csv` 中的虚构账号。既有登录账号与密码未重置。

三门课程共72道单选、多选和判断题，均附答案、解析和知识点，经服务审核发布。每个信管教学班有14个正式任务：前期和近期各3次作业、3次考试，以及2个留有待完成人员的综合任务。正式任务冻结题目、分值和应完成人员，成绩均由服务根据提交答案判定。

现有2376条任务提交记录、1080轮课程练习（12960道次作答）、360条模拟问答和1080条虚构自习记录。60名学生在三门课程中分别形成画像，共180份带证据的模拟评价，包含完成率、按时率、排名、作业/考试成绩、跨期变化、薄弱点及授权自习参考。规则生成的评价明确标记为“演示模拟评价”，未调用在线AI，也未采集视频或真实生物信息。

每门课程的已发布知识图谱有17个节点、25条关系，含课程主题、知识点及对应实践任务，三门共51个节点、75条关系。教学诊断、得分分布、高错误率题目、参与人数和知识薄弱点均从对应模拟作答记录汇总，不是手填的汇总数字。相关班级诊断副本见 `data/showcase/教学诊断-*.json`。

本批学习记录基准日为2026年11月21日，含此前约两个月数据；当前默认“最近30天”可查看前后期趋势，后续可切换“本学期”或按日期查询。搬迁时仍须完整保留 `data/learning.db`、`data/study_room.db`、所有上传资料和配置。重新打开 EXE 后进入“学生画像与任务”“习题中心”“知识图谱”“教学诊断”查看。
