## 2. 防护边界

- 提示词注入过滤是基础规则与系统提示隔离，不保证阻止所有自然语言攻击。
- 文件校验不是杀毒软件，不能检测宏病毒、零日漏洞或所有恶意内容。
- 登录和中转限流保存在单进程内存中，多实例部署必须使用网关或集中式存储。
- SSRF 校验降低常见风险，但生产环境仍应限制容器出站网络和 DNS 行为。
- MockProvider 适合离线演示，不是模型安全或回答质量证明。
- 未进行第三方渗透测试、SAST 产品扫描、Python 依赖 CVE 审计、模糊测试和高并发攻击测试。

## 3. 建议后续验证

1. 在隔离测试环境运行 Python 依赖审计工具并逐项评估 CVE；
2. 使用 OWASP ZAP 或同类工具扫描运行中的 API；
3. 接入 ClamAV 或部署平台恶意文件扫描能力；
4. 对大 PDF、复杂公式、超多页 PPTX 和异常编码文本做资源上限压测；
5. 在反向代理后验证真实客户端 IP、限流和安全响应头；
6. 用真实但脱敏课程建立人工标注问答集，分别评估检索召回、证据一致性和拒答准确率。
