# 智教伴学综合系统使用说明

## 1. 系统组成

本系统使用一个 Vue 登录入口，根据账号角色进入对应工作台：

- 教师 Vue 工作台：课程与教学班、教师知识中心、资料解析与审核、题库、教学诊断、教师 AI 设置。
- 学生 Vue 工作台：课程资料、引导式答疑、证据查看、知识卡片、关键词挖空、朗读/跟读、AI 出题、题库导入、教师发布题库、学习画像、背诵本/错题本导出，以及 AI 自习室。

后端 API 负责统一登录、权限、课程、知识、题库、学习记录和自习室接口；解析 Worker 负责较慢的文档/语义任务。统一入口为 `http://127.0.0.1:5173`，系统不再提供独立备用界面。

## 2. 启动系统（Windows 推荐）

在项目根目录打开 PowerShell：

```powershell
cd "F:\我的桌面\wmu事务\人工智能\sysytem\zhijiao_banxue"
.\start.ps1 -Mode all
```

启动后访问：

- 统一入口：`http://127.0.0.1:5173`
- API 文档：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/health`

常用模式：

```powershell
.\start.ps1 -Mode api        # 只启动 API
.\start.ps1 -Mode worker     # 只启动解析 Worker
.\start.ps1 -Mode web-dev    # 只启动 Vue 开发服务器
.\start.ps1 -Mode web-build  # 构建 Vue 生产文件
.\start.ps1 -Mode ai-check   # 检查当前 AI 配置
.\start.ps1 -Mode test       # 运行 Python 测试
```

启动脚本会自动探测 Python 3.10、3.11、3.12、Conda/Anaconda 和 `ZHIJIAO_PYTHON`。也支持 `start.cmd` 和 Linux/macOS 的 `start.sh`。

教师功能需要在真实 `server.env` 中设置 `ZHIJIAO_TEACHER_AGENT_ENABLED=1` 后启动。默认值为 `0`，同时控制教师网页调用的接口和教师 Agent；只修改 `server.env.example` 不会生效。

## 3. AI 配置

没有任何 AI 配置时，系统使用离线确定性 Mock，不需要联网，也不会因为没有 API Key 而无法打开。

支持：

- Mock：本地演示和测试，默认模式。
- OpenAI 兼容接口：在账户菜单的“AI 服务设置”中配置 Base URL、模型和 Key；网页设置按账号保存，Key 加密存储。`user_ai.env` 仅用于部署默认配置。
- Gemini：使用 Gemini OpenAI-compatible endpoint 或对应自定义提供商配置。
- Ollama：配置本机 Ollama 地址和模型，API Key 留空即可。
- Relay：配置内置云中转 URL/令牌；也可以在“AI 服务设置”中选择服务器提供的中转服务。

部署配置示例见 `.env.example`、`server.env.example` 和 `relay/.env.example`。不要把真实 Key 提交到 Git。已有的 `server.env`/`user_ai.env` 会覆盖“无配置 Mock”默认值；如果想强制 Mock，可在启动前执行：

```powershell
$env:ZHIJIAO_AI_MODE="mock"
.\start.ps1 -Mode all
```

## 4. 教师端流程

1. 打开 Vue 地址并用教师账号登录；首次登录若要求修改密码，先完成修改。
2. 进入“课程与教学班”，创建共享课程、学期和教学班，导入学生名单。
3. 进入“知识中心”，上传 PDF、DOCX、PPT/PPTX 等资料；等待解析/语义分析任务完成。
4. 在资料审核、知识树和知识候选区检查内容，调整分类、目录、学生可见性，并发布知识版本。
5. 在“习题中心”导入/编辑/审核/发布题目，可按文件夹治理题库。
6. 在“教学诊断”查看教学概况和习题学习统计：学生人数、参与人数、有效作答、正确率、薄弱知识点与高错误率题目共用顶部课程/教学班筛选。习题中心负责题库管理，可点击“到教学诊断查看学习统计”直接跳转并沿用课程。
7. 在教师 AI 设置中测试或保存个人提供商；Ollama 不需要填写 Key。

教师知识中心仍保留旧主线的高级 PDF/PPT 自适应解析、页/段证据、知识候选审核、目录治理和学生可见性控制。

勾选资料后可一次执行“审核勾选资料并发布课程”；请先完成内容预览核对。中途失败时，已完成的审核会保留，刷新后使用“继续上次审核发布”。发布失败重试复用原操作记录，避免重复生成版本。批量上传失败会保留待传文件；刷新后重新选择原目录，系统按文件名、大小和修改时间匹配未完成项，不在浏览器持久保存文件正文。

题库筛选、教学范围和档案导入默认值按账号、课程记忆。已发布正文及题目不会随教师草稿编辑而变化，修改完成后需要重新发布。需要暂停学生访问时，在知识中心点击“撤回当前发布”，核对确认框中的课程与版本后确认；只撤回该版本。

教学诊断、分析和报告采用百分制及统一学习记录。选择教学班时按作答发生时的班级统计；升级前无法确定班级的记录仍在课程汇总中，不会根据学生现在所在班级猜测归属。教师结果为匿名汇总，学生个人课程、私人导入题库及自习记录不参与统计。

“习题薄弱知识点”和题目排行使用题库发布时保存的标签与题干。修改草稿标签不会改变该版本的历史统计；重新发布后，新版本使用新标签，旧作答仍对应原版本。综合学情已有的作答快照继续使用，旧记录则读取其作答版本的发布快照。若历史快照缺失，成绩仍保留，但不使用当前草稿标签补写历史知识点。

## 5. 学生端流程

1. 打开 `http://127.0.0.1:5173`，在同一个登录页输入用户名和密码。系统依据账号角色自动进入教师工作台或学生课程页；学生首次登录按系统提示修改初始密码。
2. “课程学习”页选择已授权课程。学生账号只能看到自己被授权的共享课程和自己创建的个人课程；系统按账号记住课程，并按课程记住学习页签、题目数量和朗读速度。点击“一键准备并复习”，个人课程补齐缺少的卡片，共享课程复用教师已发布知识，随后进入挖空训练。已有卡片和手工修改会保留。
3. “先问一个问题”：输入与当前课程有关的问题，点击“开始思考”。系统先给引导提示；至少提交两次自己的思考后才允许查看课程证据答案，并可用当前题目生成巩固练习。
4. “课程与材料”：个人课程可粘贴文本、上传 PDF/DOCX/PPTX/Markdown/TXT 或图片调用视觉模型 OCR；共享课程的教师材料只读。材料解析完成后可删除个人课程材料。
5. “知识卡片”：教师已发布的知识点可以导入学生卡片。编辑标题/关键词/内容、拆分或合并卡片；长内容点击“AI 语义拆分”后先预览语块，确认后才写入独立卡片。
6. “训练巩固”：填写关键词时按关键词生成挖空；未填写关键词时，只有点击“生成挖空”才会把卡片内容交给当前 AI 服务商分析重点。浏览器本地朗读知识卡片、录制跟读回放，也可提交复述文本进行背诵评分。错误和缺失内容会进入个人背诵本。
7. “作答与测验”：共享课程可载入教师审核发布的试卷；所有课程都可以根据知识卡片生成 AI 练习或导入 PDF/DOCX/TXT/XLSX 题库，提交后查看批改结果，并导出 Word 练习册。判断题界面和错题本显示“判断题”“对/错”，不显示 `true_false`、`T`、`F` 等内部值。
8. “我的学习”：查看课程资料、知识块、背诵和练习平均分、薄弱知识统计、最近成绩，并导出 Word 背诵本和错题本。
9. 点击课程页右上角“AI 自习室”进入自习室：
   - 点击“开始自习”后，由学生当前浏览器请求摄像头权限并显示本地预览。
   - 摄像头画面不上传服务器；多名学生可以同时使用各自设备开始自习。
   - 点击“结束并保存”保存本场记录，在页面查看最近记录和累计统计；专注度和实时分由浏览器本地帧状态、专注状态、稳定性和在场率综合计算，后端只保存脱敏后的结果。
   - 没有摄像头或拒绝授权时自动保留计时，不虚构行为评分。

复习补充：教师知识有新版时，导入列表会提示更新，已有个人卡片及手工修改继续保留；可对照列表中的新版内容整理卡片。卡片拆分和合并保留各自来源。练习提交后重复点击不会增加成绩记录；要修改答案再练一次，请生成新练习。升级前页面尚未提交、没有服务端试卷记录的旧练习也需重新生成。

## 6. AI 自习室隐私说明

摄像头由浏览器 Web API 直接读取，服务器不打开摄像头、不接收视频流，也不保存图像。页面关闭、结束自习或离开路由时，浏览器媒体轨道会自动停止。自习记录按学生账号保存到 `data/study_room.db`，不会与教师课程数据混用。

## 7. 常见问题

- 页面打不开：先执行 `.\start.ps1 -Mode ai-check`，再访问 `/health`；确认 8000 和 5173 端口没有被旧程序占用。
- 本机 API 返回 502：通常是代理把 `127.0.0.1` 发给了代理软件；将 `127.0.0.1,localhost` 加入 `NO_PROXY/no_proxy`，或暂时关闭代理的本地转发。
- PowerShell 无法执行脚本：使用 `powershell -ExecutionPolicy Bypass -File .\start.ps1 -Mode all`。
- 自习室没有画面：在浏览器地址栏为当前站点允许摄像头；拒绝授权时仍可继续计时。
- 学生看不到课程：教师需要在课程与教学班中导入名单并授权；学生只能访问被授权课程。
- AI 请求失败：先切换 Mock 验证系统本身，再检查自定义 Base URL、模型名、Key、代理和 Ollama 服务状态。

## 8. 数据与安全

- 课程、用户、知识、题库数据在 `data/learning.db`；自习记录在 `data/study_room.db`。
- 上传文件会进行大小、路径、内容类型、重复文件和解析安全校验；学生端接口始终按 JWT 账号隔离。
- 退出登录、修改密码和重置密码会使该账号所有设备的旧登录和资料预览凭证失效，需要重新登录。
- 摄像头视频只存在于当前学生浏览器内存中，页面关闭或结束自习后立即释放；服务器只保存计时结果。
- 升级或大规模改动前，先备份 `data/` 和当前工作区；不要执行 `git reset --hard` 或整包覆盖主线目录。
